# mineradio-mods —— Mineradio 模块化外挂扩展包

给 [Mineradio](https://github.com/XxHuberrr/Mineradio)（Windows Electron 音乐播放器）扩展功能的**模块化外挂包**：
一条命令即可装进**未修改的官方原版**中，上游原有文件一行不改，保持高稳定性与可逆性。

开源许可证沿用 GPL-3.0-only，所有改动均以源码形式提供。

仓库：<https://github.com/tele-switc/mineradio-mods>（公开）。Clone 下来即可直接使用，
**无需单独安装 Node.js 环境** —— 可直接使用应用自带的 `Mineradio.exe`（配合 `ELECTRON_RUN_AS_NODE=1` 环境变量，见下文）。

## 架构与核心优势（对比传统直接改源码）

| 常见做法 | 本外挂包 | 优势 |

| 卸载不彻底留残留文件 | 支持按功能族精细化卸载（`--uninstall --mod <族>`），全量卸载后与原版**逐字节一致** | 具备完备的可逆性与安全性，随时干净复原 |

## 无侵入接入机制

本外挂包依托两项关键技术实现平滑接入与稳定运行：

1. **8 个标准锚点插拔机制**：不改动上游原有代码，通过成对注释标记注入最小接入行：

   ```js
   // <<mineradio-mods:main-process v0.2.0>>
   try { require('./mods-host.js'); } catch (e) { ... }
   // >>mineradio-mods:main-process
   ```

   上游 8 个锚点分布及职责：

   | 锚点 | 目标文件 | 核心职责 |
   |---|---|---|
   | `renderer-modules` | `public/js/index-loader.js` | 渲染层模块加载入口，在应用原有模块后统一装载外挂模块 |
   | `main-process` | `desktop/main.js` | 主进程宿主挂载（`require('./mods-host.js')`），管理外挂独立窗口与 IPC 通道 |
   | `server-routes` | `server.js` | 后端路由接管链，优先处理扩展接口 |
   | `server-audio-headers` | `server.js` | 保证扩展音源直链的 Referer 与 Range 请求头支持 |
   | `server-audio-type` | `server.js` | 扩展容器类型支持（如 DASH 的 mp4a、IA 的 opus、RP 的 AAC） |
   | `playback-gapless-url` | `13-playback-start-audio.js` | 扩展音源在无缝专辑预取时的地址获取 |
   | `playback-url` | `13-playback-start-audio.js` | 扩展音源的主播放地址获取与平滑替换 |
   | `preload-main` | `desktop/preload.js` | 沙箱预加载桥接（挂载于 `window.desktopMods`，提供浮窗、存档、小组件、口味档案等 20 个 IPC 接口） |

2. **开机自动维持（可选 `--autostart`）**：
   安装时加入 `--autostart`，会在 `%LOCALAPPDATA%\MineradioMods\` 部署守护脚本并注册当前用户开机巡检。当软件安装目录因更新被官方覆盖时，自动补全外挂文件与锚点标记，保障功能持续生效。

## 安装与维护命令

```bat
:: 1) 完全退出 Mineradio（托盘图标一并退出）
:: 2) 在本目录下执行：
node install.mjs                 :: 预检（Dry-run）：只打印安装计划，不修改任何文件
node install.mjs --go --autostart:: 真实安装 + 注册开机自动维持
node install.mjs --status        :: 检查当前安装状态与锚点完整性
node install.mjs --verify        :: 逐项深度校验（退出码 0 为全部正常）
node install.mjs --uninstall     :: 完整卸载（还原所有原版文件，备份保留）
node install.mjs --uninstall --mod quick-search  :: 按需仅撤销指定功能族
```

> **免 Node.js 环境使用技巧**：若本地未安装 Node.js，可将命令中的 `node` 替换为 `"C:\路径\Mineradio.exe"`，并设置环境变量 `set ELECTRON_RUN_AS_NODE=1`，效果完全相同。

## 运行特性与设计细节

- **全局热键与界面入口**：
  - 快速搜索浮窗默认热键为 `Ctrl+Space`（可通过环境变量 `MINERADIO_MODS_HOTKEY` 自定义修改或设为 `off` 关闭）；
  - 历史记录与状态快照面板热键为窗口内 `Ctrl+H`，同时在主界面控制栏注入直观的「历史」按钮；
  - 口味档案支持搜索框内一键点击开闭与详细偏好面板调节（Shift+点击可纯切开关）。
- **多窗口生命周期协同**：
  - 外挂自建的浮窗、贴边组件与进度条窗口与主播放器生命周期严格绑定，主窗口最小化或退出时外挂子窗口自动协同收纳或释放，杜绝后台游离进程。
- **纯运行时无侵入注入**：
  - 模态框、按钮及样式均在 DOM 加载时动态组装，样式通过隔离的 `<link>` 动态载入，原版 HTML/CSS 零修改。
- **数据分级与安全隔离**：
  - 状态快照与口味档案均独立落盘在 `%APPDATA%\Mineradio\` 用户数据目录下，独立于播放器缓存，无论缓存清理或软件更新都不会丢失。
